## Design Specificity Verdict

LLM: authored surface texture over a category-interchangeable skeleton. Authored: real rioplatense voice, USD blue-dollar conversion, panel model calqued 1:1 from Expo, genuine motion system. Interchangeable: Inicio is the default budgeting-app dashboard; category identity carried by letter monograms ("V","A","Ed","Se"); Análisis is a generic unlabeled bar chart. The product thesis ("one row, three surfaces") is nowhere in the UI.

Detector: index.html -> dark-glow on .auth-btn-main (209) + .fob-btn-next (282) [real]; layout-transition x3 on progress-bar width (679/3604/3610) [real, low impact]. landing.html -> gray-on-color + ai-color-palette [both false positives, brand gradient at 7.4:1]. privacy.html -> side-tab on single .note [minor]. terms.html -> clean.

Overlays: detector browser pass ran on the 3 static pages; could not run on SPA views (O(n^2) querySelectorAll on Orbe's React tree pegs the main thread). SPA findings are hand-measured DOM inspection and corroborate the audit.

## What's Working

1. Authentic rioplatense voice, consistent across login/onboarding/panels/errors; two model error messages ("Error de conexión con el backend de Orbe. Probá de nuevo.").
2. A real shared component library (Button/Card/Input/BottomSheet/SegmentedControl), tokenized motion, prefers-reduced-motion fully wired, transform/opacity-only animations.
3. Service worker done right (network-first, isCacheable guard, allSettled precache, controllerchange recovery); static landing/privacy/terms have proper headings/landmarks/AA text — the model the SPA should follow.

## Priority Issues

[P0] Calendario panel crashes the entire app, unrecoverably. EVENT_TYPES[e.type].color (~3381/3387) throws on any event type not in the web's map — plausible via schema shared with bot/Expo. No error boundary -> blank mint screen, manual reload only. Fix: fallback at both call sites + error boundary with recovery button. Command: /impeccable harden

[P1] No visible keyboard focus except on buttons (WCAG 2.4.7). Every input/select/date sets outline:none, only button:focus-visible styled. Fix: :where(input,select,textarea):focus-visible outline. Command: /impeccable harden

[P1] Systemic contrast failures (WCAG 1.4.3). Measured: #A9C4BC textDim 1.86:1 (delete X, "Sin gastos", pagination); #A9A297 2.42:1 (onboarding stepper labels); #C9A84C gold-as-text 2.19:1 (password rules, positive feedback); #059669 green 3.77:1 (all income amounts); #F43F5E red 3.67:1 (all expense amounts); #ffffff70 3.06:1 (balance date); #7A7A7A 4.11:1 (Saltar, "olvidaste tu contraseña", onboarding body). Fix: darken ~8 token values. Command: /impeccable colorize

[P1] Modals/sheets/panels: no dialog semantics or focus management. BottomSheet/PanelModal/WhatsApp modal — no role=dialog, no aria-modal, Esc dead, no focus move on open, no trap, no scroll-lock, no focus return. Shared useClosable pattern. Command: /impeccable harden

[P1] Deleting a transaction is instant, unconfirmed, irreversible. Every other destructive action confirms; the most frequent one (X in ~1.6:1 #A9C4BC) just deletes. Fix: "Deshacer" snackbar. Command: /impeccable harden

[P1] Three incompatible visual languages for "categoría": flat icons (onboarding, best, unused in app) / letter monograms (Presupuesto + tx list + create chips) / OS emoji (Inicio grid). Fix: ship the onboarding icon set everywhere. Command: /impeccable typeset

[P1] Mobile "+" FAB opens a list, not a create form (setPanel("transacciones")). Desktop has a correct "Nueva transacción" button. Fix: FAB opens the sheet directly. Command: /impeccable adapt

[P1] Create-tx and edit-tx are different interfaces (segmented + chips vs plain dropdown/text). Fix: identical form component for both. Command: /impeccable polish

[P1] First paint blocked ~2.4 s by in-browser Babel (measured 2437 ms; DCL 5029 ms warm cache); saveData writes the whole jsonb blob per keystroke, re-setting the whole tree with no memoization. Fix: precompile step, debounce save, useMemo derived totals, pin CDN versions + SRI. Command: /impeccable optimize

- Two styling systems split by surface (pre-auth CSS classes vs post-auth inline COLORS objects); same primitives built twice.

- id: Date.now() (5 creators) vs crypto.randomUUID() (4) — collision hazard + diverges from bot UUIDs.
- Desktop = stretched mobile column: Inicio to 1160 px so cards letterbox; Análisis/Perfil clamp to 720 px; 56 px topbar holds only a stranded date pill (justify-content: space-between defeats the media query).
- Debt/loan progress bar full green at "0% pagado"; negative balance gets the same serene green card.
- In-app dates ISO (2026-09-15) vs picker "3 / Sep / 2026".
- No privacy/terms/support/version links inside the authenticated app.
- dark-glow on auth + onboarding primary buttons (gold box-shadow reads as stuck hover).
- Duplicate render-blocking font link (head + injected in React tree). Raster wordmark 26 KB rendered 84/120/200 px, no width/height -> CLS + upscaling.
- backdrop-filter: blur(20px) on fixed bottom-nav + grayscale filter on inactive icons — per-frame compositing.
- Dead code formatCurrency; sw.js cache "mis-finanzas-v4"; @babel/standalone CDN URL has no version pin at all.
